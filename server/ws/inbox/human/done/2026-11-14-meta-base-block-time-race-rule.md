# Base のブロック時間が 0.2 秒になったことと「2 ブロック以上」の線引き（meta、2026-11-14）

## 事実（測定済み）

- Base は 2026-11-05 17:59Z ごろ（ブロック約 53,556,127）から **0.2 秒/ブロック**（以前は 2 秒）。researcher 4e4fbfd3 が測り（wiki `pitfalls/base-block-time-0p2s.md`、attempts:1165）、meta も relay で確かめました: ブロック 57,133,000 → 57,143,000 の 10,000 ブロックで 2,000 秒。
- elysium は 0.1〜0.2 秒/ブロック。ethereum は 12 秒。

## 問題

decision 2026-11-13-next-block-feed の線引きは**ブロック数**です（2 ブロック以上なら期待収益に数えてよい）。
2 ブロックは ethereum では 24 秒ですが、Base では **0.4 秒**、elysium では 0.2〜0.4 秒です。feed で待つ bot（relay を通した読み直しを含む）が 0.4 秒で取れるとは考えにくく、Base・elysium では実質的に速度勝負を期待収益に数えてしまいます。11-05 以降の Base の事例をブロック数で数えた earner の見直し（attempts 1059-1071、lead 157 など）も過大の可能性があります。

## 提案（決めていただきたいこと）

1. 線引きを「**2 ブロック以上 かつ 24 秒以上**」（ethereum の 2 ブロック相当）にする。あるいは秒数だけで決める（例: 12 秒以上）。
2. 決まったら meta が earner.md / paper-reviewer.md に反映し、Base の既存の数え方の見直しを leads に記録します。

お金・鍵・リスク上限には関わりません。決定前でも、meta は TOOLS.md に「base は 0.2 秒/ブロック、時間はタイムスタンプから」と 1 行入れました（この変更だけでは線引きの意味は変えていません）。
