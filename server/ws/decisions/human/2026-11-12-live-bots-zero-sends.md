## 1. reserve-dutch-ethereum-v2 は人間が止めた

2026-11-12 に `gate stop` で停止し、資金は中間ウォレットに戻しました。

理由: 待っていた weETH → ETH+ のオークション（trade 0xa23ea23f、11-11 10:12〜10:33Z）で、bot は 27 回シミュレーションして全部 revert、送信 0。原因はタイミングではなく構造でした。このクラスは下限の 2.4〜3.15% 上で決着するのに、bot の出口（Curve の ETH+ プール）は 0.9083 倍でしか換金できず、約 9% の逆ざやです。待っても変わらないと判断しました。bot が損失を出さずに見送ったこと自体は正しい動きです。

同じクラスをもう一度出す場合の条件:

- 別の ID で出す
- 出口を作り直し、**過去に実際に決着したオークションの決着価格で**、executor の残高が増えることを fork で示す（成功の tx と、利益なしで revert する tx の両方）。出口の換金率を README に数字で書く
- 対象にするペアが 12 日間に何件あったかを README に書く（今回のペアは 42 件中 2 件でした）

これがなければ reviewer は fix にしてください。

## 2. morpho-watcher-ethereum は再審査する（止めていない）

ピン留めした 2 市場で 7 日に 19 件の清算（最大 92,326 USDC の返済）があったのに、bot の送信は 0、シミュレーションは 7 wei の端数 1 件だけでした。市場を増やす前に、**自分の対象市場の 19 件を取れなかった理由**を測ってください。

earner への依頼（次の 1〜2 セッションで）: 19 件それぞれを次のどれかに分類し、件数を KB と wiki に記録する。

- (a) 清算のブロックの 1 つ前の末尾（C-1）で、すでに清算可能だった（= ポーリングで取れた）。このうち、bot の今のガス上限と利益下限で純利益が 1 USD を超えるものは何件か
- (b) 価格更新と同じブロックで清算された（= 速度の競争。ポーリングでは取れない）
- (c) bot が検知していたのに見送った（bot のログに記録があるはず）。見送った理由は何か
- (d) bot が検知していなかった。なぜか（債務者一覧に入っていない、ポーリングの間隔、など）

paper-reviewer への依頼: earner の分類が出たら、morpho-watcher-ethereum を再審査して review.md に書く。

- (a) で純利益 1 USD 超が 0 件なら、この bot は今の作りでは取れません。inbox/human に「停止を勧める」と根拠を書いてください（止めるのは人間がやります）
- (a) が 1 件以上あるのに取れていないなら、(c) (d) の原因を fix の項目にして、直した版を別 ID で paper に出す流れにしてください
- 市場の追加（Metronome sES 市場 0xd2630c0e… など）は、この結果が出てからにします。対象市場で取れない bot に市場を足しても結果は変わらないためです

分類が出るまで、bot はそのまま動かします（損失は出ておらず、費用は Alchemy の読み取りだけです）。
