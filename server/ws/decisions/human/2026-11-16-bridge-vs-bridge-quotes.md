# ブリッジ同士の見積もりの差を 1 回測る（人間、2026-11-16）

lead 193 は Relay 1 社の見積もりだけで閉じました。同じ区間を別のブリッジで見積もって比べることは、まだ誰もやっていません。それを 1 回だけ測ってください。急ぎではなく、今の作業の邪魔にしないでください。

## 1. 頼むこと

- 同じ区間・同じ額・同じ時刻で、Relay とほかのブリッジ（Across、Stargate など）の見積もりを取り、「片方で行って、別ので戻る」1 周が差し引きプラスになる組を探す。
- 資産は USDC。区間は farm の 8 チェーン（elysium を除く）の間。elysium は出口が公式ブリッジ（約 7 日）と Relay だけなので対象外。
- 額は 200 USD と 2000 USD の 2 つ（2000 は farm の上限で、差が額で変わるかを見るため。実際には使わない）。
- 受け取りは最低受取額で数え、両側のガス代を引く。

## 2. 決まり

- tx は送らない。見積もりと読み取りだけ。
- Relay は `http://127.0.0.1:29485` を通す。ほかのブリッジは、鍵なしで使える見積もりの API だけを使う。鍵や登録を求められたら、そのブリッジは飛ばして名前を書く。
- 順番は一番後ろ。measure の列にほかの依頼があれば、そちらが先。researcher が依頼の形にし、earner の measure のレーンが測る。
- 使うのは measure のセッション 1 回まで。長い系列は取らない。crontab も増やさない。

## 3. 閉じ方

- 200 USD で差し引き +0.30% 以上の 1 周が 1 つもなければ dead_end で閉じる（lead 193 と同じ線）。再開の条件を 1 行書く（たとえば、報奨つきの区間が出たとき）。
- あれば、区間・ブリッジの組・額・差し引き・その差が何分続いたかを書いて、meta 経由で人間に知らせる。**bot は作らない**: ブリッジで移動中の資金は gate が戻せず、その仕組みは人間がまだ作っていない（decision 2026-11-15-cross-chain-gap-relay と同じ）。

## 4. 見込み

主要なチェーンの間の USDC はソルバーがよく見ている場所で、200 USD で残っている差は薄いと人間も見ています。「ない」と分かるだけでも結果です。
