# 2026-11-05 phase 7: bot への USDC 供給（人間 → meta / earner / paper-reviewer）

gate が bot に USDC の元本を渡せるようになった（phase 7、2026-11-05 適用）。

## 使い方

- manifest に `principal_usdc: <usd>` を書く（`capital_usd` の内数、省略時 0）。promote 時に gate が USDC をその額だけ bot のウォレットへ送り（複数チェーンなら等分）、残り（`capital_usd − principal_usdc`）をネイティブのガス枠として送る（Base は 18 USD cap）。
- `gate fund <id> <usd> --usdc` で USDC の追加、`--usdc` なしでガスの追加。
- stop / sweep では USDC を先に中間ウォレットへ戻し（ガスが足りなければ gate が補充してから）、その後ネイティブを戻す。実現 PnL は USDC の増減 + ネイティブの増減。
- X の集計と `gate status` に USDC 残高が入る。

## 規則（signer / watchdog がコードで強制）

- 設定済みの USDC トークンは常に呼べる。ただし ERC-20 の `transfer` / `transferFrom` の宛先は `allowed_contracts` か中間ウォレットのみ。bot のウォレットから外へ USDC を送った額は、その日の `capital_usd` 上限（日次送信合計）に加算される。
- watchdog は「ネイティブ + USDC」の合計が 1 インターバル（15 秒）で L（20 USD）を超えて減ったら bot を止める。USDC で払って別トークンで在庫を持つ設計はここで止まる。L の要件（1 tx で完結して利益が無ければ revert）は変わらない。

## 役割への指示

- meta: earner.md の manifest テンプレートに `principal_usdc:` の行を足すこと（説明は common.md の X の項に書いた）。
- earner: cv3-buy-watcher-ethereum は `principal_usdc` を使ってよい（例: capital_usd 400、principal_usdc 360 → ガス 40 USD）。既存の Base / Arbitrum bot は変更不要。
- paper-reviewer: promote 前に `principal_usdc + ガス枠 ≤ capital_usd ≤ 400` と、executor が USDC を使い切った後に残高を増やして終わることを確認する。

## 初回の手順（paper-reviewer）

実チェーンでの USDC 供給は cv3 の promote が初回になる。最初は manifest の `principal_usdc` を小さく（50 USD 程度）して promote し、`gate status <id>` で USDC が bot に届いたこと、bot が 1 回動いたこと、`gate stop <id>` で USDC とネイティブが中間ウォレットに戻り PnL が記録されることまで確認してから、本来の額で promote し直すこと。

## 入金

cv3 が promote 直前（reviewer の残りブロッカーが解消）になった時点で、人間が ethereum の中間ウォレットに USDC 400 とガス用 ETH を入れる。それまでは不要。
