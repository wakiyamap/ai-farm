# op-126354ea: Inverse DBR auction arbitrageur (ethereum)

**Class D** (thin margin, threshold contest against a lower-cost incumbent). Net about +0.04 USD per tx, ~87 tx/day, ~3.5 USD/day. The whole class nets ~3 USD/day after gas. Nothing for the farm to copy at this size. KB: attempts:1372, actors:161. Ledger source `inverse_dbr_auction.buy` (installed 2026-11-16) keeps watching it.

## Addresses (each link has a tx)
- Sender EOA `0xadc26ec3d7fdcc3332e67fd74cb8df7f475a3706` → executor contract `0x126354ea9bba320c56e4fb9441509cc44e79c9f8` (tx `0x703015dd3417112b246845a6d74da7ca4b5126978edde83e7c6ac4f7ede9ff0a`, block 26424083).
- Funder and payout not traced. The DOLA profit stays in the executor (it receives the DOLA out of the Curve pool).

## Trigger and operation
- Two Inverse Finance virtual xy=k DBR auctions, both public `buyDBR(uint exactDolaIn, uint exactDbrOut, address to)` with no fee:
  - sDOLA `0xb45ad160634c528cc3d2926d9807104fa3157305` (docs.inverse.finance technical/smart-contracts). DBR reserve = DBR balance + DbrDistributor claimable, so it grows every second. K blends from prevK to targetK over 7 days (operator `setTargetK`).
  - Auction `0x933cbe81313d9dd523df6dc9b899a7af8ba073e3` (verified source name `Auction`). It mints DBR at a rate, and its proceeds go to the SaleHandler through a public `sendToSaleHandler()`, which pays the caller nothing.
- The DBR price in DOLA therefore decays until somebody buys. The operator buys from both auctions in one tx with `to` set to the Curve tricrypto DOLA/DBR/INV pool `0x66da369fc5dbba0774da70546bd20f2b242cd34d`, then calls `exchange_received` (selector 0x29b244bb) for DOLA. It is atomic and holds a DOLA float, about 50-170 DOLA per tx.
- Event: `Buy(address indexed caller, address indexed to, uint dolaIn, uint dbrOut)`, topic0 `0x89f5adc174562e07c9c9b1cae7109bbecb21cf9d1b2847e550042b8653c54a0e`.
